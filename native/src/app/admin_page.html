Server

Connected clients

Every game that holds a connection to the server. A client that stops sending is removed after 2 minutes, a logged-in player after 15.

Players in the game

The logged-in players with what the server holds in memory. A saved player's details open from the Saves tab.

Claimed names

A claimed name belongs to the devices that logged in with it. To add another device, open a link window and log in with that device while the window is open.
